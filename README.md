## What Pointify points mean

Pointify users can complete eligible activities, use daily codes, invite friends, and follow leaderboard progress. Points measure participation inside the platform. They are not money and do not guarantee token allocation, payment, conversion, withdrawal, profit, or future value.

## Safety checklist

1. Start from an official Pointify link.
2. Read the requirements for an activity before participating.
3. Never disclose a password or Telegram login code.
4. Never disclose a private key, seed phrase, or recovery phrase.
5. Ignore claims of guaranteed profit or guaranteed future token value.

For current product information, always defer to the [official Pointify website](https://pointify-token.com/).
