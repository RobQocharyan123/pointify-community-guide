คู่มือ Pointify ฉบับย่อภาษาไทย

หน้านี้ช่วยให้ผู้ใช้ค้นหาแหล่งข้อมูลทางการ เข้าใจคะแนนอย่างถูกต้อง และรักษาความปลอดภัยของบัญชี

ลิงก์ทางการ

  • เว็บไซต์ทางการ: pointify-token.com
  • Telegram bot ทางการ: @pointify_official_bot

ก่อนเข้าร่วม

ตรวจสอบกติกา วันที่ ขีดจำกัด และเงื่อนไขคุณสมบัติล่าสุดภายในผลิตภัณฑ์ คะแนนแสดงถึงการมีส่วนร่วมบนแพลตฟอร์มเท่านั้น ไม่ใช่เงิน และไม่รับประกันการจ่ายเงิน การแปลง หรือการจัดสรรในอนาคต

ความปลอดภัยของบัญชี

  1. อย่าเปิดเผย password หรือ login code
  2. อย่าให้ private key หรือ recovery phrase แก่ผู้อื่น
  3. ระวัง domain เลียนแบบและคำสัญญากำไรที่รับประกัน
  4. เริ่มต้นจากเว็บไซต์หรือ bot ทางการด้านบนเสมอ
