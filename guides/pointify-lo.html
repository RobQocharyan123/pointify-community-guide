ຄູ່ມື Pointify ແບບຫຍໍ້ພາສາລາວ

ໜ້ານີ້ຊ່ວຍຊອກຫາແຫຼ່ງທາງການ, ເຂົ້າໃຈຄະແນນຢ່າງຖືກຕ້ອງ ແລະ ປົກປ້ອງບັນຊີ.

ລິ້ງທາງການ

  • ເວັບໄຊທາງການ: pointify-token.com
  • Telegram bot ທາງການ: @pointify_official_bot

ກ່ອນເຂົ້າຮ່ວມ

ກວດເບິ່ງກົດ, ວັນທີ, ຂີດຈຳກັດ ແລະ ເງື່ອນໄຂສິດປະຈຸບັນໃນ product. ຄະແນນສະແດງພຽງການເຂົ້າຮ່ວມໃນ platform; ບໍ່ແມ່ນເງິນ ແລະ ບໍ່ຮັບປະກັນການຈ່າຍ ຫຼື ການແບ່ງປັນໃນອະນາຄົດ.

ຄວາມປອດໄພບັນຊີ

  1. ຢ່າແບ່ງປັນ password ຫຼື login code.
  2. ຢ່າເປີດເຜີຍ private key ຫຼື recovery phrase.
  3. ລະວັງ domain ປອມ ແລະ ຄຳສັນຍາກຳໄລແບບຮັບປະກັນ.
  4. ເລີ່ມຈາກ site ຫຼື bot ທາງການຂ້າງເທິງສະເໝີ.
