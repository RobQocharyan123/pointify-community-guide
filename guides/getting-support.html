Getting Pointify support

Start with the official Pointify Help Centre. Include a clear description of the feature or activity, what you expected, and what appeared instead.

Information that can help

  • The relevant page or activity name
  • A non-sensitive description of the steps taken
  • The approximate time the issue occurred
  • A screenshot with personal or credential data removed
Never send: passwords, Telegram login codes, private keys, seed phrases, recovery phrases, or remote-access credentials.

Confirm that you are using pointify-token.com and @pointify_official_bot before following support instructions.
